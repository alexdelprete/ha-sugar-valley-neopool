# 🎉 Initial Release

Home Assistant custom integration for **Sugar Valley NeoPool** pool controllers connected via **Tasmota MQTT**.

## Features

### Sensors

- Water Temperature
- pH (level, state, pump status)
- Redox (ORP)
- Hydrolysis (level, state, runtime statistics)
- Filtration (mode, speed)
- Powerunit diagnostics (5V, 12V, 24-30V, 4-20mA)
- Connection statistics (Modbus requests/responses)

### Binary Sensors

- Module presence (pH, Redox, Hydrolysis, Chlorine, Conductivity, Ionization)
- Relay states (pH, Filtration, Light, Acid)
- Water flow and tank level indicators

### Controls

- **Switches**: Filtration, Light, AUX1-AUX4 relays
- **Selects**: Filtration mode/speed, Boost mode
- **Numbers**: pH Min/Max, Redox setpoint, Hydrolysis setpoint
- **Buttons**: Clear error state

## Key Highlights

- **NodeID-based unique IDs**: Stable entity identifiers that survive MQTT topic changes
- **YAML Migration Support**: Seamlessly migrate from the YAML package with historical data preserved
- **Auto-detection**: Automatically detects MQTT topic and orphaned entities during migration
- **MQTT Discovery**: Supports automatic device discovery via Home Assistant MQTT

## Requirements

- Home Assistant 2024.1.0 or newer
- Tasmota firmware with NeoPool support
- MQTT broker configured in Home Assistant

## Installation

Available via HACS (add as custom repository) or manual installation.

See [README](https://github.com/alexdelprete/ha-sugar-valley-neopool#readme) for detailed instructions.
