# Release v0.2.18-beta.3

[![GitHub Downloads](https://img.shields.io/github/downloads/alexdelprete/ha-sugar-valley-neopool/v0.2.18-beta.3/total?style=for-the-badge)](https://github.com/alexdelprete/ha-sugar-valley-neopool/releases/tag/v0.2.18-beta.3)

**Release Date:** 2026-04-04

**Type:** Beta release - Fixes for dual NodeID migration on upgrade.

## What's Changed (since beta.2)

### 🐛 Fixed

- **Duplicate device on upgrade**: Auto-acquisition of dual NodeIDs now properly migrates the device registry identifier and all entity unique_ids from the old (real) NodeID to the new canonical (hashed) NodeID, preventing a duplicate device from being created.
- **Device removal blocked**: Fixed `async_remove_config_entry_device` incorrectly blocking all device removal from the UI.
