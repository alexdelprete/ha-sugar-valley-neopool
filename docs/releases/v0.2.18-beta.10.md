# Release v0.2.18-beta.10

[![GitHub Downloads](https://img.shields.io/github/downloads/alexdelprete/ha-sugar-valley-neopool/v0.2.18-beta.10/total?style=for-the-badge)](https://github.com/alexdelprete/ha-sugar-valley-neopool/releases/tag/v0.2.18-beta.10)

**Release Date:** 2026-04-04

**Type:** Beta release - Smart relay disable, IP fetch fix, device info enhancements.

## What's Changed (since beta.7)

### ✨ Added

- **Smart relay entity disable**: Detects which named relays are actually present in the SENSOR payload and only disables the ones that are absent. Relays that were previously disabled by the integration but are now present get re-enabled automatically.
- **Serial number**: Device info now shows the hashed System ID as serial number.
- **Tasmota firmware version**: Fetched via `Status 2` command. Firmware now shows `"Tasmota X.Y.Z / Powerunit VX.Y"`.
- **Dynamic configuration URL**: Visit link now points to the actual Tasmota device web UI (`http://{ip}`) instead of the docs page. IP fetched via `Status 5`.

### 🔄 Changed

- **Named relay entities disabled by default**: All 8 named relay binary sensors are now `entity_registry_enabled_default=False` for new installs.
- **Device removal allowed**: Users can now delete devices from the UI.

### 🐛 Fixed

- **Status 2/5 topic subscription**: Fixed MQTT wildcard issue — now subscribes to specific `stat/{topic}/STATUS2` and `stat/{topic}/STATUS5` topics with separate callbacks.
- **Device migration preserves original**: When both old and new devices exist during migration, the original device (with history) is kept and the duplicate removed.
- **Removed blind relay disable**: Beta.8 incorrectly disabled ALL relay entities including available ones. Replaced with smart detection from SENSOR payload.
