# Release v0.2.11

[![GitHub Downloads](https://img.shields.io/github/downloads/alexdelprete/ha-sugar-valley-neopool/v0.2.11/total?style=for-the-badge)](https://github.com/alexdelprete/ha-sugar-valley-neopool/releases/tag/v0.2.11)

**Release Date:** 2026-01-09

**Type:** Minor release - Dynamic device info from MQTT telemetry.

## What's Changed

### ✨ Added
- **Dynamic Device Info from MQTT Telemetry**:
  - Manufacturer now shows actual brand from `NeoPool.Type` (e.g., "Bayrol", "Hidrolife") instead of static "Sugar Valley"
  - Firmware version shows actual version from `NeoPool.Powerunit.Version` (e.g., "V3.45 (Powerunit)") instead of integration version
  - Added `async_fetch_device_metadata()` to fetch metadata during setup
  - Updated device registry dynamically after MQTT telemetry received

### 🐛 Fixed
- Fixed tests for `async_fetch_device_metadata` MQTT subscription mocking
