**Type:** Beta release - Fix entity migration for all upgrade scenarios.

## What's Changed (since beta.4)

### 🐛 Fixed

- **Complete migration fix**: Added standalone `_migrate_to_canonical_nodeid()` that runs on **every startup**, independent of whether dual acquisition ran. This handles all edge cases:
  - Entities with real NodeID unique_ids → migrated to hashed canonical
  - Duplicate entities from failed previous migrations → old duplicates removed
  - Device registry with old identifier → updated or duplicate removed
  - Already migrated → no-op (idempotent, safe to run repeatedly)

This fixes the scenario where acquisition ran (config entry updated) but entity migration failed, leaving both old and new entities in the registry.
