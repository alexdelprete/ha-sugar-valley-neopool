# Release v0.2.18-beta.16

[![GitHub Downloads](https://img.shields.io/github/downloads/alexdelprete/ha-sugar-valley-neopool/v0.2.18-beta.16/total?style=for-the-badge)](https://github.com/alexdelprete/ha-sugar-valley-neopool/releases/tag/v0.2.18-beta.16)

**Release Date:** 2026-04-04

**Type:** Beta release - Remove TelePeriod from metadata fetch to fix Status 5.

## What's Changed

### Fixed

- **Status 5 still dropped**: Removed TelePeriod command from metadata fetch.
  Any MQTT command sent after the Backlog interrupts its command queue, causing
  Tasmota to drop Status 5. SENSOR data now arrives naturally from the regular
  telemetry cycle instead of being triggered explicitly.
