# Release v0.2.18-beta.8

[![GitHub Downloads](https://img.shields.io/github/downloads/alexdelprete/ha-sugar-valley-neopool/v0.2.18-beta.8/total?style=for-the-badge)](https://github.com/alexdelprete/ha-sugar-valley-neopool/releases/tag/v0.2.18-beta.8)

**Release Date:** 2026-04-04

**Type:** Beta release - Status topic fix and relay entity disable.

## What's Changed (since beta.7)

### 🐛 Fixed

- **Status 2/5 MQTT subscription**: Fixed MQTT wildcard `STATUS+` not matching Tasmota's response topics. Now subscribes
  to specific `stat/{topic}/STATUS2` and `stat/{topic}/STATUS5` topics separately.

### 🔄 Changed

- **Disable relay entities on upgrade**: All 8 named relay entities are disabled on startup for existing installations.
  **Note:** This was too aggressive — it also disabled `relay_acid_state` which may be available. Fixed in beta.10.
