# Release v0.2.18-beta.14

[![GitHub Downloads](https://img.shields.io/github/downloads/alexdelprete/ha-sugar-valley-neopool/v0.2.18-beta.14/total?style=for-the-badge)](https://github.com/alexdelprete/ha-sugar-valley-neopool/releases/tag/v0.2.18-beta.14)

**Release Date:** 2026-04-04

**Type:** Beta release - Fix Status 5 dropped by Tasmota, device configuration URL.

## What's Changed

### Fixed

- **Status 5 dropped by Tasmota**: Replaced `Backlog Status 2; Status 5` with
  separate commands and 1s delay between them. Tasmota's NeoPool module drops
  Status 5 when busy with Modbus polling and SENSOR telemetry processing.
  TelePeriod is now sent after Status commands to avoid interference. Wait order
  also changed to Status2 -> Status5 -> SENSOR (prioritizing fast responses).
- **Device configuration URL**: Now points to the actual Tasmota device web UI
  (`<http://{ip}`>) instead of the Tasmota documentation page. Applied to both
  `get_device_info()` (used by entities) and `_update_device_registry_metadata()`
  (device registry update). Falls back to Tasmota docs URL when device IP is
  unavailable.
