# Release v0.2.5

[![GitHub Downloads](https://img.shields.io/github/downloads/alexdelprete/ha-sugar-valley-neopool/v0.2.5/total?style=for-the-badge)](https://github.com/alexdelprete/ha-sugar-valley-neopool/releases/tag/v0.2.5)

**Release Date:** 2026-01-07

**Type:** Patch release - Fixes YAML migration entity ID preservation.

## What's Changed

### 🐛 Fixed

- **YAML Migration Entity ID Preservation**: Fixed critical issue where entity IDs were not preserved after YAML
  migration due to key naming differences between YAML package and integration
  - Added `YAML_TO_INTEGRATION_KEY_MAP` translation map to bridge naming conventions
  - YAML package uses keys like `filtration_switch`, integration uses `filtration`
  - Migration now correctly maps and preserves all entity IDs

### ✨ Added

- **Missing Sensors**: Added 3 sensors that existed in YAML package but were missing from integration:
  - `hydrolysis_runtime_pol1` - Hydrolysis runtime for polarity 1
  - `hydrolysis_runtime_pol2` - Hydrolysis runtime for polarity 2
  - `connection_out_of_range` - Connection out of range responses counter
