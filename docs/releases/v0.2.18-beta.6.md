# Release v0.2.18-beta.6

[![GitHub Downloads](https://img.shields.io/github/downloads/alexdelprete/ha-sugar-valley-neopool/v0.2.18-beta.6/total?style=for-the-badge)](https://github.com/alexdelprete/ha-sugar-valley-neopool/releases/tag/v0.2.18-beta.6)

**Release Date:** 2026-04-04

**Type:** Beta release - Fix device migration to preserve original device.

## What's Changed (since beta.5)

### 🐛 Fixed

- **Device migration preserved wrong device**: When both old (real NodeID) and new (hashed) devices exist, beta.5 would remove the *original* device (with history, area assignments, automations) and keep the empty duplicate. Now correctly removes the duplicate and updates the original's identifier to the canonical hashed value.
