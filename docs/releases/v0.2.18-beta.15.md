# Release v0.2.18-beta.15

[![GitHub Downloads](https://img.shields.io/github/downloads/alexdelprete/ha-sugar-valley-neopool/v0.2.18-beta.15/total?style=for-the-badge)](https://github.com/alexdelprete/ha-sugar-valley-neopool/releases/tag/v0.2.18-beta.15)

**Release Date:** 2026-04-04

**Type:** Beta release - Simplified Status 2/5 fetch order fix.

## What's Changed

### Fixed

- **Status 5 fetch**: Simplified fix — send `Backlog Status 2; Status 5` first,
  then `TelePeriod` after. TelePeriod triggers a large SENSOR response that keeps
  Tasmota busy and drops subsequent commands, so it must be sent last. Removed
  unnecessary 1s delay between separate Status commands from beta.14.
