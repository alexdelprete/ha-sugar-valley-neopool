# Release v0.2.18-beta.4

[![GitHub Downloads](https://img.shields.io/github/downloads/alexdelprete/ha-sugar-valley-neopool/v0.2.18-beta.4/total?style=for-the-badge)](https://github.com/alexdelprete/ha-sugar-valley-neopool/releases/tag/v0.2.18-beta.4)

**Release Date:** 2026-04-04

**Type:** Beta release - Fix startup ordering for dual NodeID acquisition.

## What's Changed (since beta.3)

### 🐛 Fixed

- **Duplicate device on upgrade (root cause)**: Dual NodeID acquisition now runs **before** device registration in `async_setup_entry`. Previously, the device was registered with the old (real) NodeID first, then acquisition changed the canonical to hashed — creating a duplicate. The correct order is: acquire → register.
