# Release v0.2.18-beta.1

[![GitHub Downloads](https://img.shields.io/github/downloads/alexdelprete/ha-sugar-valley-neopool/v0.2.18-beta.1/total?style=for-the-badge)](https://github.com/alexdelprete/ha-sugar-valley-neopool/releases/tag/v0.2.18-beta.1)

**Release Date:** 2026-04-04

**Type:** Beta release - Remove SO157 prerequisite, dual NodeID recognition.

## What's Changed

### ✨ Added

- **Dual NodeID recognition**: The integration now acquires both hashed (AA55 prefix) and real NodeIDs during setup by briefly toggling SO157. Both values are stored, so the device is recognized regardless of how SO157 is set afterward. See [design document](https://github.com/alexdelprete/ha-sugar-valley-neopool/blob/main/docs/NODEID_DUAL_RECOGNITION.md) for full technical details.

### 🔄 Changed

- **SO157 no longer required**: `SetOption157` is no longer a prerequisite. The integration works with any SO157 setting and any Tasmota version. No manual SO157 configuration needed.
- **Canonical ID is hashed**: Entity unique_ids now use the hashed NodeID (AA55 prefix) for privacy by default. The real hardware NodeID is stored internally as an anchor for device recognition across SO157 changes and Tasmota upgrades.
- **Renamed sensor**: `powerunit_nodeid` → `system_id` (per @curzon01 suggestion).

### 🗑️ Removed

- SO157 runtime enforcement — no longer monitors SENSOR data to re-enable SO157.
- SO157 status display in Options flow.
- `async_query_setoption157()` and `async_ensure_setoption157_enabled()` helper functions.

## Migration Notes

- Existing entities with real NodeID unique_ids will be automatically migrated to hashed NodeID format on startup.
- The `powerunit_nodeid` sensor is automatically renamed to `system_id`.
- If you flip SO157 after setup, the device is still recognized — no re-setup needed.

## Testing Focus

Beta testers should verify:
- Fresh setup with default SO157=0 (new Tasmota with hashed NodeID)
- Fresh setup with SO157=1 (real NodeID)
- Upgrade from previous version (entity migration from real to hashed)
- Flipping SO157 after setup (device should remain recognized)
