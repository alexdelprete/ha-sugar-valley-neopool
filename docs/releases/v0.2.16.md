# Release v0.2.16

[![GitHub Downloads](https://img.shields.io/github/downloads/alexdelprete/ha-sugar-valley-neopool/v0.2.16/total?style=for-the-badge)](https://github.com/alexdelprete/ha-sugar-valley-neopool/releases/tag/v0.2.16)

**Release Date:** 2026-04-02

**Type:** Patch release - Fix incorrect relay mapping assumptions and Module JSON path bug.

## What's Changed

### 🐛 Fixed

- **Relay.State[n] assumed mapping**: Removed 3 binary sensors (`relay_ph_state`, `relay_filtration_state`, `relay_light_state`) that incorrectly assumed a fixed physical relay-to-function mapping (State[0]=pH, State[1]=Filtration, State[2]=Light). The relay-to-function mapping is configurable per installation. Use the named relay entities (`Relay.Acid`, `Relay.Base`, `Relay.Redox`, `Relay.Chlorine`, `Relay.Conductivity`, `Relay.Heating`, `Relay.UV`, `Relay.Valve`) for accurate functional status regardless of physical wiring.
- **Module/Modules JSON path bug**: Fixed incorrect JSON path for module detection sensors. The SENSOR telemetry uses `NeoPool.Module` (singular) but code was reading `NeoPool.Modules` (plural), causing module presence binary sensors (pH Module, Redox Module, etc.) to never update. These sensors now work correctly.

### ✨ Added

- **Automatic entity cleanup**: Deprecated relay entities are automatically removed from the entity registry on startup, preventing stale unavailable entities.

### 🗑️ Removed

- `relay_ph_state`, `relay_filtration_state`, `relay_light_state` binary sensors (replaced by named relay entities and existing switches).

## Migration Notes

- The 3 removed binary sensors will be **automatically cleaned up** from your entity registry on the next startup. No manual action needed.
- If you had automations referencing `relay_ph_state`, `relay_filtration_state`, or `relay_light_state`, update them to use the `filtration` switch, `light` switch, or the appropriate named relay binary sensor.
- Module presence sensors (pH Module, Redox Module, etc.) will start working for the first time after this update.
