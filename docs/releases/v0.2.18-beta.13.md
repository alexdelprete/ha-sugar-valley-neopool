# Release v0.2.18-beta.13

[![GitHub Downloads](https://img.shields.io/github/downloads/alexdelprete/ha-sugar-valley-neopool/v0.2.18-beta.13/total?style=for-the-badge)](https://github.com/alexdelprete/ha-sugar-valley-neopool/releases/tag/v0.2.18-beta.13)

**Release Date:** 2026-04-04

**Type:** Beta release - Fix device metadata fetch blocking on slow SENSOR telemetry.

## What's Changed

### Fixed

- **Device metadata fetch**: Fixed `asyncio.gather` blocking all results when
  SENSOR telemetry is slow. Status 2 (Tasmota version) and Status 5 (device IP)
  responses were lost even though they arrived in ~200ms, because the gather
  waited for all three events (SENSOR + Status 2 + Status 5) and timed out when
  SENSOR didn't arrive in time. Now waits for each event independently with a
  shared deadline, so fast responses are always collected regardless of slow ones.
