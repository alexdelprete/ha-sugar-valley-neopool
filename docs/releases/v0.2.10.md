# Release v0.2.10

[![GitHub Downloads](https://img.shields.io/github/downloads/alexdelprete/ha-sugar-valley-neopool/v0.2.10/total?style=for-the-badge)](https://github.com/alexdelprete/ha-sugar-valley-neopool/releases/tag/v0.2.10)

**Release Date:** 2026-01-07

**Type:** Patch release - Hotfix for YAML migration error.

## What's Changed

### 🐛 Fixed

- Fixed `ValueError: New entity ID should be same domain` during YAML migration
- Home Assistant's entity registry doesn't allow cross-domain entity renames (e.g., `binary_sensor.x` to `switch.x`)
- Added domain validation check to skip cross-domain mappings gracefully
- Removed invalid `relay_aux*_state` → `aux*` mappings from `YAML_TO_INTEGRATION_KEY_MAP` (binary_sensor entities cannot
  be mapped to switch entities)
