# Release v2.1.1

[![GitHub Downloads](https://img.shields.io/github/downloads/alexdelprete/ha-sugar-valley-neopool/v2.1.1/total?style=for-the-badge)][release]

**Release Date:** 2026-08-19

**Type:** Patch release - Dashboard and icon polish found while reviewing the bundled dashboards on a live
install. No breaking changes.

## What's Changed

### 🐛 Fixed

- **Auto Time Sync switch icon now renders.** Its icon was set in code via `_attr_icon` (an invalid
  `mdi:clock-sync-outline`), which overrides `icons.json` — so the v2.1.0 `icons.json`-only change had no
  effect and the icon stayed blank. All entity icons are now defined in **`icons.json` only** (single source of
  truth): the redundant/invalid code-level `_attr_icon` / description `icon=` assignments were removed, and the
  Auto Time Sync icon is now `mdi:update`.
- **Responsive dashboards labeled the pH pump tile just "Pump".** Renamed to "pH Pump" to match the
  non-responsive dashboards and avoid confusion with the filtration pump (`sensor.<name>_ph_pump`, in the pH
  Module Info section).
- **Responsive dashboards mislabeled the pH state tile as "Controller".** Renamed to "pH State"
  (`sensor.<name>_ph_state`, the pH alarm state) to match the non-responsive dashboards.

## Upgrade Notes

No action required. If you use the bundled responsive dashboards and want the corrected tile labels, re-copy
the affected tiles (or the whole dashboard).
