# Release v0.2.18-beta.7

[![GitHub Downloads](https://img.shields.io/github/downloads/alexdelprete/ha-sugar-valley-neopool/v0.2.18-beta.7/total?style=for-the-badge)](https://github.com/alexdelprete/ha-sugar-valley-neopool/releases/tag/v0.2.18-beta.7)

**Release Date:** 2026-04-04

**Type:** Beta release - Device info enhancements and relay entity cleanup.

## What's Changed (since beta.6)

### ✨ Added

- **Serial number**: Device info now shows the hashed System ID as serial number.
- **Tasmota firmware version**: Fetched via `Status 2` command. Firmware now shows `"Tasmota X.Y.Z / Powerunit VX.Y"`.
- **Dynamic configuration URL**: Visit link now points to the actual Tasmota device web UI (`http://{ip}`) instead of the docs page. IP fetched via `Status 5`.

### 🔄 Changed

- **Named relay entities disabled by default**: All 8 named relay binary sensors (Acid, Base, Redox, Chlorine, Conductivity, Heating, UV, Valve) are now disabled by default. Users can enable the ones relevant to their installation.
- **Device removal allowed**: Users can now delete devices from the UI.

### 🐛 Fixed

- **Device migration preserves original**: When both old and new devices exist during migration, the original device (with history and area assignments) is kept and the empty duplicate is removed.
