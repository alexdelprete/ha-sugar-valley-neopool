# Release v0.2.13

[![GitHub Downloads](https://img.shields.io/github/downloads/alexdelprete/ha-sugar-valley-neopool/v0.2.13/total?style=for-the-badge)](https://github.com/alexdelprete/ha-sugar-valley-neopool/releases/tag/v0.2.13)

**Release Date:** 2026-01-10

**Type:** Patch release - Bug fixes and code consolidation.

## What's Changed

### 🐛 Fixed

- **NodeID validation false positive**: Fixed `is_nodeid_masked()` incorrectly identifying valid unmasked NodeIDs as
  masked. Valid NodeIDs from Tasmota contain spaces between hex groups (e.g., `0026 0051 5443 5016 2036 3435`) which was
  triggering the mask detection. Changed detection from `"xxxx" in nodeid or " " in nodeid` to `"xxxx xxxx" in nodeid`
  pattern matching.

### 🔄 Changed

- **Consolidated NodeID validation**: Refactored `validate_nodeid()` to use `is_nodeid_masked()` internally, creating a
  single source of truth for NodeID validation logic.

### ✨ Added

- **Missing entity icons**: Added icons for `boost_mode`, `connection_out_of_range`, `hydrolysis_runtime_pol1`, and
  `hydrolysis_runtime_pol2` sensors in `icons.json`.
- Changed `modules_conductivity` icon from `mdi:flash-triangle` to `mdi:water-sync`.
